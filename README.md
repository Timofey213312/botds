# Discord Бот с 70+ командами

Многофункциональный Discord бот с системами модерации, музыки, экономики, игр и утилит.

## 📋 Функционал

### ⚖️ Модерация (8 команд)
- `!clear [кол-во]` - Очистить сообщения (1-100)
- `!kick [@участник] [причина]` - Кикнуть участника
- `!ban [@участник] [причина]` - Забанить участника  
- `!mute [@участник] [минуты] [причина]` - Выдать мут (роль)
- `!timeout [@участник] [минуты] [причина]` - Таймаут Discord (1-40320)
- `!untimeout [@участник] [причина]` - Снять таймаут
- `!report [@участник] [причина]` - Отправить жалобу

### 🎵 Музыка (12 команд)
- `!play [запрос/url]` - Воспроизвести (YT/Spotify/Яндекс/SC)
- `!pause` - Пауза | `!resume` - Продолжить
- `!skip` - Пропустить | `!stop` - Остановить
- `!queue` - Очередь | `!nowplaying` - Текущая
- `!volume [0-100]` - Громкость
- `!loop` - Повтор песни | `!loopqueue` - Повтор очереди
- `!shuffle` - Перемешать | `!leave` - Отключиться

### 💰 Экономика (8 команд)
- `!balance [@участник]` - Баланс и уровень
- `!daily` - Ежедневная награда (50-200 💰)
- `!pay [@участник] [сумма]` - Перевести деньги
- `!coinflip [сумма] [орёл/решка]` - Подбросить монетку
- `!work` - Заработать деньги (кулдаун 1ч)
- `!leaderboard [тип]` - Таблица лидеров
- `!shop` - Показать магазин
- `!buy [id]` - Купить предмет

### 🎮 Игры (7 команд)
- `!rps [камень/ножницы/бумага]` - Камень-ножницы-бумага
- `!8ball [вопрос]` - Магический шар предсказаний
- `!dice [грани]` - Бросить кость (2-100 граней)
- `!roll [кол-во] [грани]` - Бросить несколько костей
- `!slot [ставка]` - Слот-машина (10-500)
- `!guess [ставка]` - Угадай число (1-10)
- `!quest` - Активные квесты

### 🔧 Утилиты (13 команд)
- `!serverinfo` - Информация о сервере
- `!userinfo [@участник]` - Информация об участнике
- `!ping` - Проверить пинг бота
- `!avatar [@участник]` - Показать аватар
- `!weather [город]` - Показать погоду
- `!calc [выражение]` - Калькулятор
- `!remind [время] [сообщение]` - Напоминание
- `!uptime` - Время работы бота
- `!poll [вопрос] [варианты]` - Создать опрос
- `!translate [текст] [язык]` - Переводчик
- `!quote` - Случайная цитата
- `!fact` - Интересный факт
- `!stats` - Статистика бота

## 🚀 Установка

### 1. Требования
- Python 3.8+
- Discord аккаунт и сервер
- Lavalink сервер для музыки (опционально)

### 2. Настройка бота Discord
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Создайте новое приложение
3. Перейдите во вкладку "Bot" и создайте бота
4. Скопируйте токен бота
5. Включите необходимые интенты:
   - Message Content Intent
   - Server Members Intent
   - Presence Intent (опционально)

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации
1. Откройте файл `.env`
2. Замените `YOUR_BOT_TOKEN_HERE` на ваш токен бота
3. При необходимости настройте префикс команд и ID сервера

Пример `.env`:
```env
# Токен вашего Discord бота
DISCORD_TOKEN=ваш_токен_здесь

# Префикс команд бота
BOT_PREFIX=!

# ID сервера для быстрой синхронизации slash команд
# GUILD_ID=123456789012345678
```

### 5. Настройка музыки (опционально)
Для работы музыкальных команд требуется Lavalink:
1. Скачайте Lavalink с [официального сайта](https://github.com/lavalink-devs/Lavalink)
2. Настройте `application.yml`
3. Запустите Lavalink сервер
4. Бот автоматически подключится к `localhost:2333`

## ⚙️ Конфигурация

### База данных
Бот использует SQLite базу данных для хранения:
- Данных пользователей (баланс, XP, уровень)
- Инвентаря
- Напоминаний
- Опросов
- Товаров магазина

### Настройки музыки
По умолчанию бот пытается подключиться к Lavalink на `localhost:2333`.
Для изменения настроек отредактируйте функцию `connect_wavelink()` в `main.py`.

## 🛠️ Разработка

### Добавление новых команд
1. Создайте функцию команды в соответствующем модуле
2. Декорируйте её с помощью `@bot.hybrid_command`
3. Настройте параметры с помощью `@app_commands.describe`
4. Добавьте проверку прав при необходимости
5. Импортируйте и настройте модуль в `main.py`

### Структура команды
```python
@bot.hybrid_command(name="имя", description="Описание")
@app_commands.describe(параметр="Описание параметра")
@commands.has_permissions(право=True)  # Опционально
async def команда(ctx: commands.Context, параметр: тип):
    """Документация команды"""
    try:
        # Логика команды
        await ctx.send("Результат")
    except Exception as e:
        await ctx.send(f"❌ Ошибка: {e}")
```

## 🔒 Безопасность

### Токен бота
Никогда не делитесь вашим токеном бота. Файл `.env` добавлен в `.gitignore`.

### Права доступа
- Модерационные команды требуют соответствующих прав на сервере
- Экономические команды доступны всем участникам
- Музыкальные команды требуют подключения к голосовому каналу

## 🐛 Устранение проблем

### Бот не запускается
1. Проверьте установлены ли все зависимости: `pip list`
2. Убедитесь что токен в `.env` корректен
3. Проверьте права бота на сервере

### Музыка не работает
1. Убедитесь что Lavalink сервер запущен
2. Проверьте подключение к `localhost:2333`
3. Обновите yt-dlp: `pip install --upgrade yt-dlp`

### Команды не отображаются
1. Убедитесь что бот имеет права на использование slash команд
2. Перезапустите бота для синхронизации команд
3. Проверьте интенты в настройках бота
